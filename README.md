# Тестирование портала «Конференции.РФ»

**МДК 05.03 — Тестирование информационных систем.** Выполнила Кукина Алла Владимировна, группа 4ИСП9-45, 2026.

**Объект:** собственное учебное веб-приложение из репозитория `MDK.09.01`, стек Flask + SQLite.

| Задание | Состав |
|---|---|
| 3.1 | Чек-лист (16 пунктов), 5 тест-кейсов, образец баг-репорта и протокол исполнения |
| 3.2 | Анализ HTTP-запроса через Chrome/Edge DevTools; инструкция и поля для фактических значений |
| 3.3 | Граничные и негативные тесты регистрации/входа, Selenium Page Object |

**Важно:** результаты Selenium и снимки DevTools заполняются после настоящего запуска. В материалах не заявляются несуществующие дефекты и успешные прогоны.

## Как запустить автотесты

1. Рядом распаковать `MDK.09.01` и `MDK.05.03`.
2. В каталоге `MDK.09.01` выполнить `pip install -r requirements.txt` и `python run.py`.
3. В каталоге `MDK.05.03` выполнить `pip install -r requirements.txt` и `python -m pytest -q autotests`.
4. Selenium Manager может автоматически найти драйвер Chrome; необходим установленный Chrome/Edge и доступ к драйверу.
5. Сделать снимок результатов и положить в `screenshots/3.3_формы`.
